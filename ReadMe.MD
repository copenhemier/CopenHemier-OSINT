# CopenHemier OSINT

CopenHemier OSINT is a desktop OSINT (Open Source Intelligence) tool built with Python and Tkinter. It provides a clean terminal-style interface for gathering publicly available information from TikTok profiles and organizing it into an easy-to-read report.

The project was created as a learning project focused on Python, GUI development, web requests, and OSINT concepts.

## Features

* TikTok profile lookup
* Follower, following, likes, and video statistics
* Account metadata collection
* Public bio extraction
* External link detection
* Cross-platform username search shortcuts
* JSON report exporting
* Terminal-inspired interface
* Lightweight and easy to run

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/CopenHemier-OSINT.git
cd CopenHemier-OSINT
```

Install dependencies:

```bash
pip install requests
```

Run the application:

```bash
python CopenHemier_OSINT.py
```

## Requirements

* Python 3.10+
* requests
* tkinter

Most Python installations already include Tkinter.

## How It Works

The tool requests publicly accessible TikTok profile pages and extracts information that is already available to anyone viewing the profile. No authentication, bypasses, or private data access are used.

Information displayed may include:

* Username
* Display name
* Account statistics
* Bio information
* Public links
* Account identifiers
* Public profile metadata
